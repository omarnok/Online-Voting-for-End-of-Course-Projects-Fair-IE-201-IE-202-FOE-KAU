🔧 How to Create Supabase Project (5 minutes)

  1. Go to Supabase.com and click "Start your project"
  2. Sign up with Google or email
  3. Click "New Project" → Name it IE-Voting
  4. Choose a strong database password → Click "Create new project"
  5. Wait 1-2 minutes for the project to be ready
  6. Go to Project Settings → API (in left sidebar)
  7. Copy the URL and anon/public key
  8. Paste them above and click "Connect"

⚠️ Important: Run This SQL First

In the SQL Editor, run:

CREATE TABLE projects (id TEXT PRIMARY KEY, name TEXT NOT NULL, instructor TEXT, category TEXT NOT NULL, section TEXT, team TEXT, image TEXT, members JSONB DEFAULT '[]', created_at TIMESTAMPTZ DEFAULT NOW()); CREATE TABLE votes (id TEXT PRIMARY KEY, category TEXT NOT NULL, project_id TEXT NOT NULL, count INTEGER DEFAULT 0, last_updated TIMESTAMPTZ DEFAULT NOW()); CREATE TABLE voters (university_id TEXT PRIMARY KEY, name TEXT NOT NULL, email TEXT, phone TEXT, voted_categories JSONB DEFAULT '[]', registered_at TIMESTAMPTZ DEFAULT NOW()); CREATE TABLE settings (key TEXT PRIMARY KEY, value JSONB DEFAULT '{}'); INSERT INTO settings (key, value) VALUES ('voting', '{"active": true}'); ALTER TABLE projects ENABLE ROW LEVEL SECURITY; ALTER TABLE votes ENABLE ROW LEVEL SECURITY; ALTER TABLE voters ENABLE ROW LEVEL SECURITY; ALTER TABLE settings ENABLE ROW LEVEL SECURITY; CREATE POLICY "Allow all" ON projects FOR ALL USING (true); CREATE POLICY "Allow all" ON votes FOR ALL USING (true); CREATE POLICY "Allow all" ON voters FOR ALL USING (true); CREATE POLICY "Allow all" ON settings FOR ALL USING (true);

Then enable Realtime: Database → Replication → Source → Toggle ON all 4 tables
